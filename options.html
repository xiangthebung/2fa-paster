Setting up full messages

Not finished

Only needed for the full-messages option. Google grants Gmail access to a registered application rather than to extensions in general, so you register one — it belongs to your Google account, and no third party sits in the middle.

  1. Copy this extension's ID

    Google ties the credential to this exact extension.

    …

  2. Turn on the Gmail API

    Create a Google Cloud project if you do not have one, then enable the Gmail API for it.

    New project Enable Gmail API

  3. Set up the consent screen

    Choose External, fill in the app name and your own email, then add your Google account under Test users. Leave it in testing mode: reading message bodies needs a scope Google restricts, so a published app would need a security review. In testing mode it works for the accounts you list, which is all you need.

    Audience and test users

  4. Create the OAuth client

    Under Clients, choose Create client, pick application type Chrome Extension, and paste the ID from step 1 into Item ID. Copy the client ID it gives you — it ends in .apps.googleusercontent.com.

    Clients

  5. Give the client ID to the extension

    Save it in a file called client-id.local beside package.json, then rebuild and reload. The file is git-ignored, so the credential stays out of the repository. 

    npm run build

    Then open chrome://extensions and press reload on 2FA Paster.

How it behaves

Finding the mail

Full messages only

The Gmail API reader searches recent messages whose subject or body uses the vocabulary of a code delivery. Spam, trash, drafts and sent mail are never read. The inbox preview does not search — it only ever sees unread inbox mail.

Shortcut

No keyboard shortcut is set. It is the quickest way to use this — no popup, no clicking — so it is worth having one you will remember. Chrome keeps shortcuts on its own page, and will leave the suggested combination unassigned if something else already claims it.

What this can see

  • Inbox preview. Fetches Gmail's own inbox feed with the session cookie your browser already has. It returns unread inbox mail only, and only the sender, subject, a snippet and a timestamp — never a full message, and never anything you have already read.
  • Full messages. Uses the gmail.readonly scope, because Google has no narrower scope that includes message bodies. Used only to fetch the few recent messages that match the code search.
  • Codes are held in session storage, which lives in memory and is dropped when Chrome closes. Nothing is written to disk and nothing is sent anywhere except to Google.
  • No server, no analytics, no third party. If you use the full-messages option, the OAuth client belongs to your Google account, not to this extension's author.
